Como Funciona o ConSub

Consulte as etapas de cadastro, busca de horários e registro de pedidos.

Passo 1

Faça seu Cadastro

  1. 1Acesse o formulário de inscrição na fila
  2. 2Informe os dados de cadastro
  3. 3Selecione a especialidade e a urgência informada
  4. 4Escolha o estado, a cidade e, se desejar, uma unidade
  5. 5Confirme o cadastro para registrá-lo
💡 Dica: Peça ajuda de um familiar para fazer o cadastro, se necessário.
Passo 2

Consulte os horários

  1. 1Abra a lista de consultas disponíveis
  2. 2Filtre por especialidade, cidade ou profissional
  3. 3Confira data, horário, unidade e profissional
  4. 4Selecione o horário para abrir o formulário de pedido
📱 Mantenha o seu celular por perto e com crédito ou plano ativo.
Passo 3

Registre o pedido

  1. 1Escolha a consulta desejada
  2. 2Se necessário, inclua um pedido de transporte
  3. 3Confira as informações e envie o pedido
  4. 4O pedido fica registrado e não confirma nem reserva a consulta
💡 Confira os dados antes de enviar. O pedido de consulta não reduz a quantidade de vagas disponível.

Informações do cadastro

O formulário reúne os dados necessários para organizar cada inscrição.

Especialidade Tipo de atendimento informado no cadastro
Urgência Nível informado no formulário
Localidade Estado, cidade e unidade de referência
Descrição Observação opcional sobre a necessidade

Orientação Especial para Idosos

O formulário apresenta os campos em etapas claras e pode ser preenchido com apoio de uma pessoa de confiança.

Pelo celular

Peça ajuda para revisar o nome, a data de nascimento e os contatos antes de enviar.

Revise os campos

Confira os dados de contato e a localidade selecionada antes de registrar a inscrição.

Na UBS

Se houver uma unidade de referência, selecione-a no formulário. Esse campo é opcional.
